# 国际独立站域名接入与阿里云配置

面向部署与运维：目标是一套平台同时服务多个租户，每个租户既可以用平台子域
（`租户标识.平台根域`），也可以绑定自己的域名（`shop.客户公司.com`），
独立访问、独立证书、内容互不串站。

> 应用侧的站点隔离、发布快照与域名校验都已经在代码里完成；本文只解决
> **DNS → 入口 → 证书 → 回源** 这四层基础设施，以及后台需要在哪几处配置。

---

## 1. 先理解应用侧的路由规则

| 规则 | 说明 |
| --- | --- |
| Host 判定站点 | 公开请求按 Host 反查：先匹配自定义域名（需校验通过），再解析平台子域 `<slug>.<根域>` |
| 路径兜底 | 无法按 Host 判定（未配置根域、总开关关闭、域名未校验）时，全部回落到本站路径 `/geo-site/{标识}` |
| 主站不受影响 | 主站域名走 Next.js；只有 `*.根域` 与已绑定的客户域名进入独立站投递 |
| 探针 | 校验域名时请求 `https://<域名>/_geo-site/probe?token=…`，必须回源到本系统并回显令牌 |
| 爬虫文件 | `robots.txt` / `sitemap.xml` / `llms.txt` 同样按 Host 输出，反代不要拦 |
| 多语言 | 默认语言在根路径，其他语言在 `/{语言码}/…`；语言清单在站点设置里维护 |

**反代硬性要求**：原样透传 `Host` 与 `X-Forwarded-Proto`。任何一层把 Host 改写成
后端内网域名或固定域名，都会导致所有租户落到同一个站点或直接 404。

---

## 2. 系统内需要配置的三处

1. **主站域名**：平台管理员 →「系统与内容 · 系统设置」→ 站点域名（例如
   `https://www.example.com`）。平台子域根域默认取它的主机名并去掉 `www.`。
2. **独立站管理**：平台管理员 →「独立站管理」：
   - 「计费与脚本策略」：确认「按域名访问总开关」开启；需要覆盖根域 / CNAME 目标时
     填写「平台子域根域覆盖」「自定义域名 CNAME 目标覆盖」；
   - 「域名接入」：核对页面展示的生效值（根域、泛解析域名、CNAME 目标、探针路径），
     这些值就是下面 DNS 与反代要用的值；
   - 「回源自检」：输入任意 Host，确认能落到目标站点。
3. **租户绑定域名**：建站者进入「工作台 → 国际独立站 → 编辑站点 → 域名」，添加域名、
   勾选备案/内容责任承诺，然后按页面提示加 TXT 与 CNAME，点「校验」。

> 关闭「按域名访问总开关」会让平台子域与已生效自定义域名**一律不认站**，只保留
> `/geo-site/{标识}` 路径访问。用于回源尚未就绪时先挡住错误域名。

---

## 3. DNS 规划

以平台根域 `example.com`、入口域名 `origin.example.com` 为例（均替换为实际值）：

| 记录 | 主机记录 | 类型 | 值 | 用途 |
| --- | --- | --- | --- | --- |
| 泛解析 | `*` | A 或 CNAME | 网关公网 IP / `origin.example.com` | 所有平台子域 |
| 客户域名 | `shop`（客户侧） | CNAME | 平台后台展示的 CNAME 目标 | 自定义域名接入 |
| 校验 | `_geo-site-verify.shop`（客户侧） | TXT | 绑定后页面显示的令牌 | 域名归属校验 |
| 探针 | 同上域名本身 | A/CNAME | 同上 | HTTPS 探针必须可达 |

普通 A 记录 TTL 建议 600 秒；切换入口时先把 TTL 调小，避免回滚等待。

## 4. 三种入口方案

### 方案 A：阿里云 ESA「SaaS 管理器」（推荐，客户自有域名）

适用：SaaS 多租户，客户域名不属于平台，无法为每个客户域名提前申请证书；香港 / 海外节点
免备案，国内节点要求客户域名已完成 ICP 备案。

要点：

1. 在 ESA 控制台开通站点并完成平台根域接入；
2. 使用 **SaaS 管理器** 添加「客户自定义域名」能力，获得 ESA 分配的 CNAME 接入点；
3. 在平台「独立站管理 → 计费与脚本策略 → 自定义域名 CNAME 目标覆盖」填写 ESA 回源域名
   （或按 ESA 要求填写其接入点，以后台「域名接入」页展示值为准）；
4. 客户在其 DNS 里把 `shop.customer.com` CNAME 到该目标；ESA 自动签发并续期证书；
5. ESA 回源到平台入口时保留原始 Host，应用按 Host 反查站点；
6. 客户仍要在绑定页添加 `_geo-site-verify` TXT，平台校验通过后域名生效。

优点：客户免改证书、免备案（境外节点）、可叠加 WAF/CDN 与缓存规则。
注意：ESA 的回源 Host 改写策略必须配置为「保留客户端 Host」，否则所有客户域名会落到
同一个站点；若必须改写，需在回源侧改成按 `X-Forwarded-Host` 判定（默认实现不读取该头）。

### 方案 B：阿里云 ALB + ECS/ECI（国内已备案）

适用：客户域名均已备案、流量需要统一入口与证书管理。

1. ALB 监听 443，上传泛域名证书（`*.example.com`）；客户域名逐个上传证书或使用多域名证书；
2. 转发规则：
   - `*.example.com` → 后端服务器组；
   - 客户域名 → 同一后端服务器组（或按需分组）；
   - 不建议配置「基于路径」的规则，应用依赖 Host 与原始路径；
3. 健康检查路径使用 `/_geo-site/probe`（不带 token 时返回 400 也算存活，具体以实际响应为准）
   或使用主站健康检查；
4. 后端 ECS/ECI 上的 Nginx 必须再次透传 Host（见第 5 节）；
5. 安全组只放行 ALB 网段到后端端口。

### 方案 C：单机 Nginx（最小成本，前期推荐）

一台 ECS 跑 Next.js + Hono + Nginx，Nginx 用泛域名证书接住 `*.example.com`，
自定义域名可以先用「逐域名证书」，或直接走方案 A 的 ESA。

仓库内已提供两份可复制模板：

- `infra/nginx/enterprise.conf`：主站 + 独立站同机部署（含 default_server 处理）；
- `infra/nginx/geo-site.conf`：独立站专用，泛域名 443 + 客户域名示例。

替换 `<BACKEND>`、`<ROOT_DOMAIN>` 与证书路径后 include 到 `http {}` 即可。

## 5. 反向代理关键配置

```nginx
server {
  listen 443 ssl http2;
  server_name *.example.com;
  ssl_certificate     /etc/ssl/example.com/fullchain.pem;
  ssl_certificate_key /etc/ssl/example.com/privkey.pem;

  location = /_geo-site/probe {
    proxy_pass http://<BACKEND>/_geo-site/probe;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
  }

  location / {
    proxy_pass http://<BACKEND>/api/public/geo-sites/by-host/;
    proxy_set_header Host              $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
    proxy_http_version 1.1;
  }
}
```

注意：

- `location /` 的 `proxy_pass` 结尾斜杠不能丢，否则站内子路径（`/products`、`/blog/xxx`）会 404；
- 不要开启 `proxy_redirect` 改写，页面内链接由应用按语言与路径生成；
- 静态资源如果走 OSS/CDN，直接由 CDN 域名提供，不要让站点域名承载大文件。

## 6. 证书

| 场景 | 做法 |
| --- | --- |
| 平台子域 | 泛域名证书 `*.example.com`（DNS-01 签发，注意 `example.com` 本身需单独覆盖） |
| 客户域名（ESA） | ESA 自动签发与续期，无需平台干预 |
| 客户域名（直连本机） | 客户提供证书或平台为该域名申请证书；Nginx 按 `server_name` 加载 |
| 证书续期 | 泛域名证书到期前 30 天续期并 reload；到期会导致所有子域同时不可访问 |

## 7. 数据与存储

- **默认**：单库多租户，按 `siteId` 与站点归属做隔离，适合中小体量；
- **强隔离**：把独立站内容库拆到独立 RDS 实例/库，应用侧通过连接配置切换，域名层无需改动；
- **静态资源**：OSS + CDN。页面 HTML 由应用实时渲染（读取已发布快照），不依赖 CDN 缓存；
- **备份**：站点快照与域名台账在同一库，按现有数据库备份策略执行即可。

---

## 8. 安全与合规

- 国内节点：客户域名必须完成 ICP 备案；香港 / 海外节点免备案；
- 绑定页要求勾选内容责任承诺（可在「独立站管理」关闭，但不建议）；
- 第三方脚本有平台域名白名单与单页条数上限，且只在独立域名投递，不要在前置 WAF 放开任意脚本；
- WAF/CDN 必须保留原始 Host；如启用「回源改 Host」，请先跑「回源自检」验证；
- 平台根域与主站域名不允许被客户绑定（后端已拦截）。

## 9. 验收清单

按顺序逐项验证，任一项失败先修该层再往下：

1. `dig +short demo.example.com` 返回入口 IP / CNAME；
2. `curl -I https://demo.example.com/` 返回 200，且正文是该租户的站点；
3. `curl -I https://demo.example.com/_geo-site/probe` 不是 404；
4. `curl -I https://demo.example.com/robots.txt` 返回该站点的 robots；
5. 客户域名 CNAME 生效后，在绑定页点「校验」→ 状态变为「已生效」；
6. `curl -I https://shop.customer.com/` 返回该客户站点；
7. 后台「回源自检」分别输入 `demo.example.com` 与 `shop.customer.com`，均显示「命中站点」；
8. 切换语言访问 `https://shop.customer.com/en/`（若启用了英文）能正常渲染；
9. 关闭「按域名访问总开关」后，上述域名回落到 `/geo-site/{标识}`，确认开关生效后再打开。

## 10. 常见故障

| 现象 | 排查 |
| --- | --- |
| 所有域名都显示同一个站点 | 反代/WAF 改写了 Host；或 `X-Forwarded-Host` 被当成 Host。先查入口配置 |
| 平台子域 404 | 泛解析未生效；或平台根域覆盖配置与 DNS 后缀不一致 |
| 子域能访问，自定义域名不能 | 域名未校验通过（TXT / CNAME / 探针任一步失败）；或总开关关闭 |
| 校验一直失败 | TXT 记录值含引号/空格；CNAME 未生效；探针被 WAF 拦截；域名解析到内网地址（后端拒绝私有 IP） |
| 主站域名被当成独立站 | 主站 server 未显式列主站域名，被 default_server 抢走 |
| 页面能开但站内链接 404 | `proxy_pass` 结尾斜杠丢失，子路径没有接到 `by-host/` 后面 |
| 客户域名证书报错 | ESA 未签发 / 直连方案未加载该域名证书 / SNI 未覆盖 |
