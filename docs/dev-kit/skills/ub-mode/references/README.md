# ub-mode 来源与配套工具

- 文本来源：本仓 `docs/ub-mode/SKILL.md`（迁入真源时未改动正文）。
- 思想来源：loosely based on [@poteto](https://github.com/poteto) 的 `poteto-mode` / `pstack`。
- 本仓 `SKILL.md` 提到的配套工具均为**独立外部仓库，本仓不随附**：
  - [unclebob/crapper](https://github.com/unclebob/crapper)
  - [unclebob/dryer](https://github.com/unclebob/dryer)
  - [unclebob/mutator](https://github.com/unclebob/mutator)
  - [unclebob/uml-viewer](https://github.com/unclebob/uml-viewer)

如果运行环境没有这些工具，跳过对应步骤并如实说明；不得虚构覆盖率、重复率或变异测试结果。

调用方式：Codex 使用 `$ub-mode`，Claude Code 使用 `/ub-mode`。
