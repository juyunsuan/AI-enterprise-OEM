## 0. 一句话结论

现在"浅"，不是浅在页面少，而是浅在**分析引擎缺地基**：没有时尚标签体系、没有商业指标生产者、没有图表层、没有报告/PPT 生成器。本方案不改底层采集（已成熟），而是把「**标签体系 → 指标计算 → 可视化 → AI 报告/PPT → 款式衍生**」这条分析主链补齐，全部复用现有 AI 网关、多维表格、BotBuddy 三条底座。

## 1. 标杆拆解：专业平台到底做了什么

### 1.1 POP 趋势「爆款衍生」(gen_54 页面结构)
页面以**一个真实爆款为锚点**，向四个方向做"衍生决策"，每条由趋势团队/AI 点评：
- **配色焕新**（爆款核心点）— 主色/辅色与撞色解读
- **细节衍生**（增长机会）— 门襟/口袋/工艺等细节改良
- **材质替换**（衍生方向）— 面料升级建议
- **廓形调整**（趋势团队点评）— 版型与风格走向

顶部给"本周监测 6 平台 / 1,573 个爆款方向 / 最高月销"这类**数据可信度锚**，正文回答设计师四个问题：**下季做什么 / 这个方向行吗 / 别人怎么做 / 怎么落地**。前瞻提前 12–18 个月，第三方验证准确率 85%+（注意：是"方向准确率"，不是单品销量的精确预测）。

### 1.2 知衣科技（电商 + 社媒双轮）
- **属性洞察/一键分析**：圈选日期+品类，取热销 TOP N，一键统计**风格 / 面料 / 袖长 / 版型 / 图案 / 款式细节**的分布。
- **行业洞察**：品类结构、**价格带分布**、颜色/面料属性，多维度**交叉分析**。
- **红蓝海四象限**：横轴销量占比、纵轴环比增长，下钻到"品类×价格带×颜色×面料×细节"的极细颗粒度。
- **竞品/竞店监控**：SKU 生命周期曲线、小时级数据更新、断码/预售异动预警。
- **以图搜图/智能识别设计要素**：识别款式要素后一键匹配全网同款/相似款并看声量与销售表现。
- **趋势分析报告**：大数据 + 资深趋势团队人工把关，"流行什么"+"好不好卖"。

### 1.3 提炼给我们的三条专业范式
1. **以标签为原子**：一切分析都建立在"款式→多维结构化标签"之上，标签体系是地基。
2. **占比 × 增速 × 交叉** 三件套：单维分布只是描述，专业洞察来自"某细分组合的占比与环比"。
3. **数据 + AI/专家 双层叙事**：图表负责"是什么"，AI 负责"为什么/怎么办"，报告负责结构化落地。

| 层 | 现状（已具备） | 缺口（导致"浅"） |
|---|---|---|
| 采集 | 数据源/排班/批次/主备通道（host+local）齐全，`INSIGHT_COLLECTION_SKILLS` 三包 zip 已产出，`landRows` 幂等去重可用 | 电商预置表有 price/sales/review 列但**未驱动任何商业指标**；社媒视觉素材未做时尚化打标 |

**根因**：缺"时尚标签体系 + 商业指标生产者 + 图表层 + PPT 生成器"四块地基。其余都是可复用的成熟件。

```
① 采集层(已有, 小幅扩展)
```

## 4. 分层详细设计

### 4.1 采集层（仅扩展，不重构）
- 沿用采集先行架构与 `INSIGHT_PURPOSES`（trend-element / trend-color / trend-commercial），按目的分治各走各端点（遵守规范「智慧分析两侧采集配置分治」）。
- **新增第三张预置表「趋势标签观测」**（在 `INSIGHT_PRESET_TABLES` 增加模板）：列 = 素材URL/来源平台/采集批次/款式类目/色彩主副色(HEX)/色彩系/廓形/长度/图案/工艺细节/材质/品牌店铺/价格/销量/评分/上架时间/打标版本。dedup 锚 = 素材URL。用途：把"电商商业字段"和"视觉标签"落到同一行，供 4.3 交叉分析直接消费。
- 电商表补 `subscription_id` 血缘列（修已知缺口），保证批次回溯。
- BotBuddy 专注采集，不参与报告生成（硬边界，见需求 §3.1/§4.3）。

### 4.2 时尚标签体系 & 视觉分析引擎（地基）
- **新建标签体系（contracts 常量，可版本化）**：五大维度的受控词表，先覆盖专业高频项，**分阶段逼近"2000+ 标签"目标**：
  - 色彩：色系 + 关键色（对色名/HEX，如 雾霾蓝 #A7C4BC）；
  - 廓形：A-line / straight / oversize / fitted / 茧型 / X型…；
  - 长度：超短/短/中/长/超长；
  - 图案：条纹/格纹/印花/纯色/字母/民族…；
  - 工艺细节：抽绳/褶皱/拼接/压扣/流苏/镂空…；
  - 材质：棉/麻/丝/毛/醋酸/尼龙/针织/牛仔/皮革…
  > 诚实口径：需求写"2000+ 标签 90%+ 准确率"是**远期目标**。P1 先交付"5 维 × 每维 30–60 词"的可用体系，词表可扩展，准确率随打标样本迭代；对外承诺需按实测收敛，不照抄标杆数字。
- **重构打标 prompt**：`vision.service.ts` 增加"时尚款式理解"专用 schema，输出**结构化 JSON**（各维度取受控词 + 置信度 + HEX），不再复用通用 caption/labels。规则式兜底保留。
- **打标自动化**：把 `Insight_tagAssets` 从"手动点按钮"升级为采集批次后置的排班任务（复用 `RpaChromeScheduleService` / host 通道同款调度），新素材自动入打标队列；写 `visual` 指标按标签聚合。

### 4.3 指标计算层（补齐商业/色彩/增速）
- 新增 `commercial` **生产者**：在 `insight.service` 加"趋势重算"任务，对电商/标签观测表按维度聚合出
  - 占比（份额，0–100 归一）= 该值销量或款数 / 总体；
  - 环比 `growthRate`（对齐现有字段）；
  - 价格带分桶销量、爆款多因子打分（销量+增速+评分+评论，权重进 `InsightSetting.scoreConfig`）。
- 色彩趋势：从打标 HEX → 色系聚类 → 时序 `visual` 指标；产出关键色上升/下降榜。
- 统一写 `InsightMetric(metricType ∈ {visual, commercial})`，`period` 支持日/周/月，供曲线与透视。

### 4.4 多维分析能力
- **单维分布 + 占比 + 环比**：每维度 TOP N 榜与趋势。
- **交叉透视**：品类×颜色、廓形×材质、价格带×风格等（内存透视起步；量大再评估给 `DataTableService` 加服务端聚合，现有 `listRows` 仅分页、无聚合）。
- **红蓝海四象限**：X=销量占比、Y=环比增长，散点 + 象限背景（修现有"表格硬编码四行"）。
- **价格带分析**：分桶分布、趋势、与品牌/材质交叉。
- **竞品/品牌对比**：按 shop/brand 分组的雷达/对比表 + 上新与动销。
- **趋势预测**：时序外推（线性/季节性统计法）+ `aiJson` 文字解读与置信区间说明；输出"未来 1–2 季走向"叙述，**明确标注为方向性预测**，与 85% 方向准确率口径对齐，不虚构单品销量精确值。

### 4.5 可视化层
- **引入图表库**（现无）：决策点 D1，二选一——
  - A. `@ant-design/charts`(G2Plot)：与 antd 同生态、上手快，覆盖折线/柱/饼/雷达/散点；热力/词云需补充。
  - B. `echarts`(+`echarts-wordcloud`)：一套覆盖折线/热力/散点象限/雷达/词云/时间轴缩放，导出 PNG 成熟，推荐。
- 重构 `trends/page.tsx`：六页签升级为「趋势总览 / 色彩 / 廓形·材质·细节 / 商业·价格带·竞品 / 红蓝海 / 采集(源·排班·批次)」。
- 交互：时间轴滑块、多条件筛选（周期/平台/类目/订阅）、下钻（点标签→关联款式列表）、色卡墙、图导出 PNG。
- 遵守版式规范：工具页签条与"新建/生成"按钮分排（对齐企微 SCRM 口径）。

### 4.6 报告与 PPT 生成层（需求核心诉求之一）
- **报告 = 结构化工程对象**：把现有 markdown 快报升级为「封面/目录/引言/大盘/色彩/廓形·材质·细节/商业·价格带·竞品/红蓝海/预测/结论建议/附录」分节数据模型（`InsightReport` 扩展 `outlineJson`）。
- **AI 生成**：`aiJson` 按节产出叙事（"是什么+为什么+怎么办"），注入图表与真实数字，杜绝占位假数据（遵守规范：后端不做占位）。
- **PPTX 生成器（新建，产品侧自研）**：仓内无 pptx 能力 →
  - 方案：新增服务端依赖 `pptxgenjs`（纯 Node，产可编辑 .pptx），在 insight 旁挂 `trend-report.service`；`generateReport` 产 outline → 渲染 PPTX → 经 `deliverableSink` 存数字资产/OSS，返回下载链。
  - **图表入 PPT 的图片来源** = 决策点 D2：
    - (a) 前端把每图导出 PNG 上传后拼版（保真、可控，工程量中）；
    - (b) 服务端渲染（resvg/sharp，重、需装原生依赖，与「服务端不装重依赖」偏好冲突，慎用）。推荐 (a)。
  - 品牌定制：**内置 2–3 套专业模板**（数据看板/趋势企划/品牌提案）+ **用户自定义模板上传**（logo/主色/字体，或 .pptx 母版），配置存 `InsightSetting`，渲染由 `pptxgenjs` 套用母版（对齐 D4）。
- **多格式**：PPTX（主）+ Markdown（已有）+ PDF（PPTX 转或前端打印，P3 再评估）+ XLSX 数据表（可用轻量 `exceljs`，或直连多维表格导出 CSV）。
- **说明**：会话侧 Presentations/office 技能是助手能力、非产品代码，不能作为产品自研路径；产品内 PPT 必须由本服务的生成器产出。需求 §3.4 提到的"IDE 处理报告生成"理解为：报告生成走平台后端 AI，而非 BotBuddy 采集端。

### 4.7 款式衍生（对标 gen_54，差异化亮点）
- 选一个真实爆款为锚，AI 沿"配色焕新/细节衍生/材质替换/廓形调整"四向出**点评 + 方向建议**（text 模型，引用同标签下市场占比/增速作为依据）。
- 进阶（P3/P4）：用 image 模型槽做**图生图**衍生款示意（改色/换材质），产出灵感图并入报告"怎么落地"节。
- 回答设计师四问：下季做什么/这方向行吗/别人怎么做/怎么落地，形成从"分析"到"决策"的闭环。

- **D5 数据真实度边界（由我拍板）**：✅ 采用 **「核心高价值源打透 + 平台清单渐进」**。理由与口径：
  - P0（女装）把采集**深度**压在现有可合规、可浏览器采集的闭集平台上——电商 **淘宝/天猫 + 抖音电商 + 京东**（供 price/sales/review → commercial 指标 + 款式图 → 视觉标签），社媒 **小红书 + 抖音**（供穿搭热词/声量 → 前置趋势信号）。这些已在 `INSIGHT_PLATFORMS`/`INSIGHT_ECOM_PLATFORMS` 闭集内，链路已跑通，最快产出可信数据。
  - "1000+ 平台 / 四大时装周秀场 / INS / WGSN" 短期**不硬承诺**：先在平台清单登记为"待接入"状态位，通过 `site` 自定义采集包定向补可公开来源（品牌官网 lookbook 等），秀场/海外/付费源走"人工导入 + 后置"。
  - 一句话：**宁要 3 类源的真数据打透，不要 1000 源的清单空壳**——与 D6 的实测披露口径一致。
- **D6 对外指标口径**：✅ 已定 **同意降级** — 把"90%+ 准确率 / 2000+ 标签 / 1000+ 平台"作为**内部目标**，对外文案改为"标签体系可扩展、趋势方向性预测、已覆盖核心电商+社媒平台"并按实测披露，避免不实承诺。

## 9. 验收与风险（诚实口径）
- 验收锚：① 趋势页真实曲线非表格；② 色彩/商业页签有数；③ 四象限是散点且有纵轴；④ 一键产出的 .pptx 可编辑、图表为真数据截图、无占位假文；⑤ 打标全自动、幂等不重复。
- 主要风险：VLM 标签准确率依赖样本迭代（先小步可验证再扩词表）；`pptxgenjs` 图表保真依赖 PNG 管线（先做最小闭环再品牌化）；秀场/海外源采集合规与可达性（D5）；服务端不引入重原生依赖的约束（影响 D2-b）。

### 缺口补齐（v1.1→v1.2）
1. **采集后置自动打标**：新增 `autoTagEnabled` 设置（默认关），`autoTagForUser()` 仅在开启时跑一小批；已挂进 `InsightScheduler.runOnce`。前端看板筛选区加「自动打标」开关。→ 不默认烧额度。
2. **电商血缘列**：`INSIGHT_PRESET_TABLES.ecommerce` 补 `subscription_id` 列（`ensurePresetTable` 自动补列，无 Prisma 迁移）。
3. **趋势标签观测预置表**：新增 `wearTag` 预置表模板（六维标签+血缘，url 幂等锚），`tagAssets` 结构化打标后按 url 幂等落表；表 id 缓存于 `scoreConfig.wearTableId`（无迁移）。
4. **PPT 内置模板 + 自定义品牌**：`deckTheme()` 内置 3 套（数据看板/趋势企划/品牌提案）+ 用户品牌覆盖（主色/字体/logo，存 `scoreConfig.deckBrand`）；`renderDeckPptx` 套主题、封面贴 logo。报告页加格式(PPTX/PDF)+模板选择。自定义母版上传受 pptxgenjs 能力限制，落地为「品牌主题」而非 .pptx 母版注入。
5. **PDF + 图生图**：`generateDeck(format:'pdf')` 走 `renderDeckHtml()` 打印就绪报告（CJK 零字体依赖、图表内嵌 base64、打开即触发浏览器打印为 PDF）；`deriveStyle(withImages, imageUrl)` 经 `ContentMediaService.editImage` 出真实衍生款图，无图像通道/无参考图时如实降级、不伪造。

### 对外口径（D6 收敛，仍适用）
标签体系 v1（约 100 词，可扩展）；预测为方向性线性外推；平台覆盖按 D5「核心电商+社媒打透、清单渐进」。
