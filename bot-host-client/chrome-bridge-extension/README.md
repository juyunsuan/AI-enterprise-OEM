# BotBuddy 浏览器桥接（Chrome / Edge 插件）

让 BotBuddy 客户端里的 Agent 能操作**你正在用的这个浏览器**：列标签页、打开网址、读页面正文、点击元素、填写输入框。

## 安装

1. Chrome / Edge 地址栏打开 `chrome://extensions/`（Edge 为 `edge://extensions/`），右上角开启「开发者模式」。
2. 点「加载已解压的扩展程序」，选中本文件夹（`chrome-bridge-extension`）。
3. 点工具栏上的插件图标，填入：
   - **桥接地址**：默认 `http://127.0.0.1:35911`（与客户端「插件」页显示的一致）；
   - **桥接令牌**：在客户端「插件 → Chrome 插件桥接」点「复制桥接信息」取得。
4. 点「保存并连接」，状态显示「已连接」即接通。

## 能做什么 / 不做什么

| 能力 | 说明 |
| --- | --- |
| `chrome_tabs` | 列出所有标签页（标题、地址、是否当前激活） |
| `chrome_open` | 新标签打开一个 http(s) 地址 |
| `chrome_read` | 读取当前标签页正文（最多 2 万字） |
| `chrome_click` | 按 CSS 选择器点击元素 |
| `chrome_fill` | 按 CSS 选择器填值并触发 input/change |

- 桥接只监听 `127.0.0.1`，不接受外部网络连接；
- 不读 Cookie、不修改请求头、不绕过验证码；
- 页面内容只回传给本机客户端里的模型，不上传平台。

## 安全提示

桥接令牌等价于「允许本机客户端操作这个浏览器」，不要发到群里或写进公开文档；怀疑泄露时在客户端「插件」页重启桥接重新生成令牌，并在插件弹窗里更新。
